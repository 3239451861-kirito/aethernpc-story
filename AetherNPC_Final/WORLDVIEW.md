# 银月城世界观设定

> AetherNPC 完整世界观：从第一纪元到黑森林之夜，从七件圣物到三个结局。

## 一、世界总览

这片大陆曾沐浴在月神的光辉之下。传说在 **第一纪元**，虚空之主试图撕裂现实，将世界拖入永恒的虚空。七位贤者以月神赐下的祝福铸造了 **七件圣物**，在如今的银月城以东、黑森林深处的祭坛上，将虚空之主封印于维度裂隙之中。

封印维持了千年的安宁，但圣物散落、封印渐弱，黑暗正在重新聚集。

## 二、银月城

银月城是大陆上最古老的城市之一，建于第一纪元。整座城墙由 **月长石** 砌成——这种稀有的魔法矿石能够吸收月光并释放净化之力，因此每逢满月之夜，城墙都会泛起柔和的银光。

城市的灵魂是 **月神信仰**：居民相信月长石是月神的眼泪，满月之夜会聚集在月长石祭坛前祈祷净化。月神图书馆里保存着自第一纪元以来的全部典籍，管理员伊莲是城中公认最博学的学者。

城中关键地点：

- **醉龙酒馆**：老板玛格丽特消息灵通，城里没有她不知道的风声——前提是你付得起金币。
- **市政厅**：城主坐镇于此，负责商队、税收与城防，也掌握着城市最深的秘密。
- **月神图书馆**：第一纪元的历史、圣物图鉴与上古地图都收藏在这里。
- **月神殿**：祭司莉亚娜守护月神祭坛，满月祈福能为出征者赐下月光祝福。
- **银月矿坑**：出产大陆最纯净的月长石，但近来大批矿石被运往黑森林方向。

## 三、影子教团

**影子教团** 是一个崇拜虚空之主的秘密组织，成员身穿黑袍，相信通过活人献祭可以重新打开通往虚空维度的大门。

教团行事隐秘，渗透进商队、矿场甚至市政厅的账房。他们近年来活动频繁，暗中搜集七件圣物的下落，目标是在封印彻底失效前将虚空之主迎回现世。

## 四、七件圣物

七件圣物由七位贤者铸造，封印虚空之主后散落大陆各处：

| 圣物 | 说明 |
| --- | --- |
| 虚空之钥 | 封印的核心，据传藏于黑森林深处的上古废墟 |
| 晨曦之镜 | 映照真实，可识破幻象与伪装 |
| 潮汐之笛 | 能号令河流与海潮 |
| 烬灭之锤 | 锻造与毁灭之力并存 |
| 星语之冠 | 聆听星辰的低语与预言 |
| 影缚之环 | 束缚暗影与灵体 |
| 月辉之盾 | 以月长石锻造，可抵御虚空侵蚀 |

## 五、黑森林与上古废墟

黑森林位于银月城以东，常年被黑色雾气笼罩，连最老练的猎户也不愿深入。森林深处藏着一座 **上古废墟**——第一纪元贤者们封印虚空之主的祭坛遗迹。

废墟的浮雕记录着当年的战斗：七贤者、七件圣物、以及被封印的虚空之主。如今，这里被影子教团占据，祭坛中央悬浮着 **虚空之钥**。

世代守护黑森林边界的 **守林人** 熟悉林中的每一处陷阱与道路，他们是商队失踪案最早的目击者。

## 六、商队失踪事件（故事的起点）

失踪的商队包括：

- 翡翠商队（12 人）
- 铁盾商队（8 人）
- 星光商队（15 人）

最后一批星光商队在三天前失踪于黑森林。守林人最后一次见到他们时，商队正沿着河道走向废墟方向。市政厅的账本里同时出现了一笔可疑的月长石交易，买家的署名只有一个月牙标记——那是影子教团的徽记。

## 七、主线剧情

玩家抵达银月城城门，在守卫巴顿处得知商队失踪的消息，随后可选择：

1. **城门路线**：询问守卫 → 获得商队与黑森林的情报 → 进城
2. **贿赂/潜行路线**：塞金币买路，或偷偷溜进城（可能被抓）
3. **图书馆路线**：在月神图书馆研读第一纪元的历史，追踪圣物与废墟的地图
4. **酒馆路线**：向玛格丽特购买消息，收集教团与月长石交易的风声
5. **市政厅路线**：查阅账本、面见城主、接下调查任务
6. **月神殿路线**：参加满月祈福，获得月光祝福，并听闻七件圣物的传说
7. **矿区路线**：翻看矿场发货账本，追查月长石与月牙印记的流向
8. **守林人路线**：雇守林人卡恩带路，或请他辨认黑袍脚印

三条线索最终都指向黑森林深处的上古废墟。

## 八、三个结局

在祭坛前，玩家必须做出最终抉择：

- **英雄结局（ending_hero）**：夺走虚空之钥并加固封印，银月城恢复宁静，你成为传说中的英雄。
- **背叛结局（ending_betrayal）**：加入影子教团，将虚空之钥送入祭坛，银月城陷入长夜。
- **救赎结局（ending_rescuer）**：先救出被囚的商队幸存者，再销毁虚空之钥，让月光重新照亮黑森林。
